WENDy.solve — Function

Solve the inverse problem for the unknown parameters solve( prob::WENDyProblem, p₀::AbstractVector{<:Real}, params::WENDyParameters=WENDyParameters(); alg::AbstractWENDySolver=TrustRegion(), kwargs... )

Arguments

  • prob::WENDyProblem : An instance of a WENDyProblem for the ODE that you wish to estimate parameters for
  • p₀::AbstractVector{<:Real} : Inital guess for the parameters
  • params::WENDyParameters : hyperparameters for the WENDy Algorithm
  • alg::AbstractWENDySolver=TrustRegion() : (optional) Choice of solver
    • WLS : weak form least squares
    • IRLS : WENDy generalized least squares solver via iterative reweighted least squares
    • TrustRegion : (default) optimize over the weak form negative log-likelihood with a trust region solver. This approximates the maximum likelhood estimator. Note: this is the only solver that will respect the constraints
    • ARCqK : optimize over the weak form negative log-likelihood with adaptive regularized cubics algorithm
    • HybridTrustRegionOELS(oe) : hybrid solver that first optimizes with the trust region solver then passes the result as an intialization to the output error least squares problem oe (an OutputErrorProblem)

Returns a WENDySolution (the estimate p̂, iterations, iterates, retcode, time and the solver). For uncertainty in the estimate see Ĉ, Ccons and C∇²ℓ. For output error least squares on its own see OutputErrorProblem.

WENDy.ℓ — Method
ℓ(prob::WENDyProblem, p)

Weak form negative log-likelihood ℓ(p) = ½rᵀS⁻¹r + ½log|S| + (KD/2)log(2π), where r(p) is the weak residual and S(p) its covariance. This is half the paper's ℓ(p) = logdet S + rᵀS⁻¹r plus a constant (same minimizer); kept for comparison with earlier results.

WENDy.∇²m — Method

The hessian ∇²ℓ = ∇²m + ∇²logdet. With y = S⁻¹r, vⱼ = ∂ⱼLᵀy and W[:,j] = ∂ⱼSy = (1-δ)(∂ⱼL(Lᵀy) + Lvⱼ) (matvecs only): ∂ᵢⱼm = ∂ᵢⱼrᵀy + ∂ᵢrᵀS⁻¹∂ⱼr - (S⁻¹∂ᵢr)ᵀWⱼ - (S⁻¹∂ⱼr)ᵀWᵢ + WᵢᵀS⁻¹Wⱼ - (1-δ)[vᵢᵀvⱼ + ⟨∂ᵢⱼL, y(Lᵀy)ᵀ⟩] ∂ᵢⱼlogdet = (1-δ)[⟨S⁻¹∂ᵢL, ∂ⱼL⟩ + ⟨S⁻¹L, ∂ᵢⱼL⟩] - ½tr(AᵢAⱼ), Aⱼ = S⁻¹∂ⱼS ∇²m only needs solves with J right hand sides (S⁻¹∇r, S⁻¹W), and is the approximate hessian (approxHessian = true). For ⟨S⁻¹∂ᵢL, ∂ⱼL⟩, ∂ᵢL = E ∘ blockdiag(B[:,:,i,m]) with E = Φ ⊗ ID, so one solve Z = S⁻¹E (Mp1D right hand sides) replaces the J solves S⁻¹∂ᵢL: ⟨S⁻¹∂ᵢL, ∂ⱼL⟩ = ∑ Ẑ[e,m,d₂] B[d₂,d₁,i,m] B[e,d₁,j,m] with Ẑ = _ΦᵀM(Φ, Z). The J matrices Aⱼ (KD × KD) take one product through Φ (∂L_Mᵀ) and one solve each. The terms with second derivatives (∂ᵢⱼrᵀy and ⟨∂ᵢⱼL, ·⟩, see _∂²ψ) are zero for a linear weak form; they are linear in their second argument, so ∇²ℓ takes ⟨∂ᵢⱼL, S⁻¹L - y(Lᵀy)ᵀ⟩ in one contraction instead of one for m and one for logdet.

WENDy.∇ℓ — Method

With the blocks, ½yᵀ∂ⱼSy = (1-δ)yᵀQⱼy and ½tr(S⁻¹∂ⱼS) = (1-δ)⟨S⁻¹, Qⱼ⟩, and since Qⱼ = ∑ₐqₐL̃ₐL̃ⱼ₊₁ᵀ both are ∑ₐqₐCₐ,ⱼ₊₁ for C = ⟨B, L̃ₐL̃ᵦᵀ⟩ with B = yyᵀ and S⁻¹. So ∇ℓ = ∇m + ∇logdet takes one contraction with B = S⁻¹ - yyᵀ: ∂ⱼℓ = Gⱼᵀy + (1-δ)∑ₐqₐCₐ,ⱼ₊₁

WENDy.∇ℓ — Method

∇ℓ = ∇m + ∇logdet, with vⱼ = ∂ⱼLᵀy: ∂ⱼm = ∂ⱼrᵀy - ½yᵀ∂ⱼSy = ∂ⱼrᵀy - (1-δ)vⱼᵀ(Lᵀy) ∂ⱼlogdet = ½tr(S⁻¹∂ⱼS) = (1-δ)⟨S⁻¹L, ∂ⱼL⟩ both through Φ and B (section 2): vⱼ from ΦᵀY, and ⟨S⁻¹L, ∂ⱼL⟩ from T = _ΦᵀM(Φ, S⁻¹L) (D × Mp1 × D).

WENDy.OutputErrorProblem — Type
OutputErrorProblem(tt, U, f!, J; params=WENDyParameters())

The output error least squares problem: find p (and optionally u₀) that minimize ½‖û(tt; p, u₀) - U‖² where û solves the ODE du/dt = f(u, p, t). This is the common alternative to the weak form, provided for comparison and for the hybrid solver HybridTrustRegionOELS.

The forward solves need OrdinaryDiffEq.jl, which WENDy only loads on request: run using OrdinaryDiffEq first (using OrdinaryDiffEqRosenbrock is enough for the default solver, Rodas5P).

Arguments

  • tt::AbstractVector{<:Real} : vector of times (equispaced)
  • U::AbstractVecOrMat{<:Real} : Corrupted state variable data
  • f!::Function : Right hand-side of the differential equation, f!(du, u, p, t)
  • J::Int : number of parameters (to be estimated)
  • params::WENDyParameters : (optional) the forward solve settings fsAlg, fsReltol, fsAbstol and fsU0Free are used

Fields

  • tt, U, f!, J : as above
  • D::Int : number of state variables
  • Mp1::Int : number of time points
  • u₀::AbstractVector{<:Real} : initial condition taken from the data, U[1,:] (the initial guess for u₀ when fsU0Free)
  • params::WENDyParameters : default parameters for solve
  • sens::OESensitivity : the forward sensitivity system that gives the jacobian (see OESensitivity)

Fields

  • diagReg::Real = 1.0e-10 : Regularization constant for the covariance computations
  • radiusMinTime::Real = 0.01 : Minimum test function radius (in time units matching _tt)
  • radiusMaxTime::Real = 5.0 : Minimum test function radius (in time units matching _tt)
  • numRadii::Int = 100 : Maximum number of radii to be checked in the min radii detection sub-algorithm
  • radiiParams::AbstractVector{<:Real} = 2 .^(0:3) : Multiplied by the minRadius to give a list of radii to use when building the test function matrix
  • testFunSubRate::Real = 2.0 : Corresponds to how much we should sup-sample in the min radii detection sub-algorithm
  • maxTestFunCondNum::Real = 1e4 : Maximum Condition number of the test function matrix after svd reduction
  • minTestFunInfoNum::Real = 0.95 : Minimum information (σₖ/σ₁)in the test function matrix after svd reduction
  • Kmax::Int = 200 : Hard maximum size on the test function matrix
  • Kᵣ::Union{Nothing,Int} = 100 : how many test function to spread through the time domain in the min radii detection sub-algorithm
  • fsAbstol::Real = 1e-8 : forward solve absolute tolerance for solving ordinary differential equation
  • fsReltol::Real = 1e-8 : forward solve relative tolerance for solving ordinary differntial equation
  • nlsAbstol::Real = 1e-8 : nonlinear least squares absolute tolerance (only used in the IRLS WENDy algorithm)
  • nlsReltol::Real = 1e-8 : nonlinear least squares relative tolerance (only used in the IRLS WENDy algorithm)
  • nlsMaxiters::Int = 1000 : nonlinear least squares maximum iterations (only used in the IRLS WENDy algorithm)
  • optimAbstol::Real = 1e-8 : absolute tolerance (used by all other optimization algorithms)
  • optimReltol::Real = 1e-8 : relative tolerance (used by all other optimization algorithms)
  • optimMaxiters::Int = 200 : maximum iterations (used by all other optimization algorithms)
  • optimTimelimit::Real = 200.0 : maximum time in seconds for each optimization algorithm. IRLS checks it after every iteration and bounds each inner nonlinear least squares solve by the time it has left; the hybrid methods apply it to each stage
  • fsAlg = nothing : forward solve algorithm (any OrdinaryDiffEq ODE solver) used by the output error least squares problem; nothing uses Rodas5P() (see OutputErrorProblem)
  • fsU0Free::Bool = true : Specifies if the forward solve algorithm should also optimize over the initial condition
  • approxHessian::Bool = false : Second order solvers (TrustRegion, ARCqK and the hybrid methods) use the hessian ∇²m of the Mahalanobis distance m(p) = ½rᵀS⁻¹r instead of ∇²ℓ, leaving out the curvature of the log-determinant term (see ∇²m). This skips the most expensive part of the hessian, turning these into quasi-Newton methods. Often several times faster when that term is small relative to the rest of the hessian, but it can converge to a worse point when it is not, so check the result against the exact hessian on a new problem

WENDy.WENDyProblem — Type
WENDyProblem

A WENDyProblem holds the weak form of the parameter inverse problem: the (transformed) data, the test functions, the weak form (see LinearWeakForm, NonlinearWeakForm) and a workspace for evaluating the weak form negative log-likelihood (see ℓ, ∇ℓ!, ∇²ℓ!) and the weak residual (see weakResidual!, weakJacobian!, weakCovariance). For the output error (forward solve) least squares problem see OutputErrorProblem.

Constructor

WENDyProblem(
    _tt::AbstractVector{<:Real}, 
    U::AbstractVecOrMat{<:Real}, 
    _f!::Function, 
    J::Int; 
    linearInParameters::Bool=false, 
    noiseDist::Type{<:Distribution}=Normal, 
    params::WENDyParameters=WENDyParameters(), 
    constraints::Union{Nothing,AbstractVector{Tuple{<:Real,<:Real}}}=nothing, 
    ll::LogLevel=Warn
)

Arguments

  • _tt::AbstractVector{<:Real} : vector of times (equispaced)
  • U::AbstractVecOrMat{<:Real} : Corrupted state variable data
  • _f!::Function : Right hand-side of the differential equation Must be of the form f!(du, u, p, t)
  • J::Int : number of parameters (to be estimated)
  • linearInParameters::Bool=false : (optional) specify whether the right hand side is `linear in parameters' for improved computational efficiency
  • noiseDist::Type{<:Distribution}=Normal : (optional) specify the distribution of the measurement noise. Choose either Normal for additive Gaussian noise of LogNormal for multiplicative LogNormal noise.
  • params::WENDyParameters : (optional) struct of hyper-parameters for the WENDy Algorithm (see the doc for WENDyParameters)
  • constraints=nothing : (optional) Linear box constraints for each parameter, ∀j ∈ [1, ⋯,J], ℓⱼ ≤ pⱼ ≤ uⱼ. Accepts constraints as a list of tuples, [(ℓ₁,u₁), ⋯]. Note: this only is compatible with the TrustRegion solver.
  • ll::LogLevel=Warn : (optional) see additional algorithm information by setting ll=Info

It can also be built from data that was already transformed and its weak form (e.g. to rebuild a saved problem) with WENDyProblem(tt, X, Φ, Φ̇, σ, b, wform::WeakForm, params::WENDyParameters; noiseDist=Normal, constraints=nothing, ll=Warn) where wform = weakForm(f!, tt, X, Φ, Φ̇, σ, b, J; linearInParameters, noiseDist).

Fields

  • dims::WENDyDims : the sizes D (state variables), J (parameters), Mp1 (time points), K (test functions) and KD = K*D
  • tt, X : times and data (X = log(U) for LogNormal noise, with nonpositive data removed)
  • Φ, Φ̇ : test function matrices Φ and Φ̇
  • σ : estimated noise level in each state variable
  • b : -vec(V′X)
  • noiseDist : the noise model the problem was built for, Normal or LogNormal
  • constraints : vector of tuples containing linear constraints for each parameter
  • ws::WENDyWorkspace : the weak form and shared state for ℓ(p), ∇ℓ(p) and ∇²ℓ(p)

WENDy.WENDySolution — Type
WENDySolution

What every solver returns:

  • p̂::Vector{Float64} : the parameter estimate
  • û₀::Union{Nothing,Vector{Float64}} : the estimated initial condition (output error least squares and the hybrid solver when params.fsU0Free), otherwise nothing
  • iterations::Int : number of iterations
  • iterates::Matrix{Float64} : the parameters at each iterate (J × iterates, starting at p₀)
  • retcode::Symbol : :success, :maxiters, :timelimit or :failed, from the solver's own status
  • time::Float64 : seconds spent in the solver
  • alg::String : the solver, e.g. "TrustRegion"

The parameter covariance at the estimate is available from Ĉ, Ccons and C∇²ℓ.
